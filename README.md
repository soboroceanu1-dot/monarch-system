MONARCH 2.0 — Awakening Beta

Corecții: întrebări cu selecție multiplă (1, 9, 14, 15, 16), opțiuni pentru mișcare/sport/alimentație, direcții suplimentare, campanie cu misiuni zilnice personalizate și progres zilnic.

Instalare: fă export de siguranță din aplicație; încarcă cele 5 fișiere la rădăcina repo-ului GitHub Pages. Nu include date sensibile.

Limitări: misiunile din panoul Campania mea sunt marcate manual; XP nu este conectat încă; planul este bazat pe reguli și nu pe AI; progresul este salvat local în browser. Testul complet nu a fost validat într-un browser Telegram real.

Pentru a reface onboarding-ul după Alpha, deschide Campania mea și apasă „Refă evaluarea inițială”. Progresul principal din joc rămâne neschimbat.
