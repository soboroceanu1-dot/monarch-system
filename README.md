# MONARCH SYSTEM 1.1 — Hunter Mode

Actualizare peste versiunea 1.0, cu migrare automată a progresului local.

- Shadow Debt numai pentru amânări voluntare în domeniile învățare/profesional.
- Break the Cycle: recuperare printr-un pas mic, maximum o dată pe zi pentru fiecare sarcină.
- BOSS personalizate, raportul ultimelor 7 zile și ștergerea misiunilor personalizate.
- Fără penalizări pentru alimentație, mișcare, somn sau zile de pauză.
- Datele rămân exclusiv în stocarea locală a browserului Telegram; exportați backup din Setări.

**Instalare:** încărcați `index.html`, `style.css`, `app.js` și `README.md` în rădăcina repository-ului GitHub Pages, înlocuind fișierele vechi.
